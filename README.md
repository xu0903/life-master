# LifeMaster

手機優先的生活管理 PWA：習慣打卡、待辦清單、多益單字卡。可加到 iPhone 主畫面、離線使用。

## 功能

- **習慣打卡**：自訂習慣（圖示、顏色、順序），顯示連續天數 🔥
- **習慣記錄方式**：打卡、次數、喝水（依水壺容量換算毫升）、時間（計時器或番茄鐘照實際秒數記入）、組數（可依 App 內的閱讀 / 聽力 / 單字 / 文法練習自動完成）
- **每日多益 10 字**：多益題庫 4,500 多字，分 600 / 800 / 900 三級與 21 個主題，含 KK 音標、英英解釋、同反義詞、例句與美 / 英 / 澳發音；答錯的字以間隔重複（Leitner 盒子）安排複習，完成後自動打卡
- **學測 7000 單與進階字彙**：每日單字也可選學測 1–6 級（單字與級別取自大考中心字表，中文解釋與例句為本 App 另行編寫），或 6,384 字的進階字彙（中高級、高級、學術三級）；英檢字表待取得授權後開放
- **字典**：多益、學測與進階字彙合併，可用英文或中文搜尋，依字首、級別與主題瀏覽
- **單字卡**：自訂題目（輸入單字自動帶出詞性、意思、例句與同反義詞）、翻牌測驗、可翻整個多益題庫或依主題翻
- **多益閱讀**：六份原創模擬試題（Part 5–7 各 100 題），可計時模擬考或分題型練習，附中文解析；「刷 10 題」從約 1,600 題 Part 5 抽題，「填空 2 篇」有近 100 篇 Part 6
- **多益聽力**：兩份聽力試題（Part 2–4，共 188 題），AI 錄製的對話語音，可調速，對答案後顯示逐字稿
- **多益文法 20 單元**：重點講解、例句、小測驗，並依閱讀弱點推薦單元
- **弱點分析與錯題本**：依考點統計答對率，錯題自動收集重練；另有每日 10 題
- **錯題生字卡組**：閱讀、聽力、文法答錯的題目裡，多益與學測 3 級以上的單字自動收進卡組
- **多益菜單**：依目標分數與練習強度排一週的練習，做完自動打勾，並可連動記到「讀書」習慣
- **今日任務**：首頁整理今天要做的事（每日單字、多益菜單、習慣、到期待辦），並建議要複習的錯題生字與錯題本
- **待辦清單**：優先級、分類、截止日、逾期提醒、重複（每天 / 每週 / 隔週 / 每月）、月曆檢視、今日完成進度
- **夥伴房間**：建立房間、用邀請碼加入，互看今日進度並互相督促
- **帳號與同步**：用 Email 註冊，手機、平板登入同一個帳號自動同步資料；也可只開雲端備份，換手機時用還原碼找回資料
- **推播通知**：App 關著也會收到待辦提醒
- **番茄鐘、多個考試倒數、本週回顧、學習月報（可分享）、成就**
- **統計**：每月打卡熱力圖、各習慣完成率、單字學習曲線
- **主題**：9 款淺色、7 款深色，或跟隨系統
- **自動更新**：有新版時自動更新並重新載入，設定頁顯示版本號與更新內容
- **備份**：匯出 / 匯入 JSON

房間、帳號同步、雲端備份與推播都需要設定 Supabase，見 `supabase/README.md`。

資料存在瀏覽器的 localStorage。沒有登入帳號或開啟雲端備份時，只有待辦提醒的標題與時間（推播用）、以及房間裡的今日進度數字會上傳；登入帳號或開啟雲端備份後，App 資料會存到 Supabase 以便同步與還原。

## 開發

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # 輸出到 dist/
npm run deploy   # 建置並發佈到 GitHub Pages（gh-pages 分支）
```

App 圖示由九宮格圖 `design/icon-sheet.png` 切出來：`node scripts/split-icons.mjs`（輸出到 `public/icons/`，並以第 8 格覆蓋預設的 PWA 圖示）

## 內容產生腳本

- `python scripts/parse-wordlists.py`：從 `wordlists/` 裡的官方字表 PDF 抽出單字與級別（PDF 不放進版本庫，請自行從大考中心與 LTTC 官網下載）
- `npx tsx scripts/enrich-words.ts`：用 OpenAI 補上中文解釋、英英解釋與例句，輸出 `src/data/vocab.json`
- `npx tsx scripts/gen-audio.ts`：產生聽力題的語音檔（`public/audio/`）
- 以上需要在 `.env.local` 放 `OPENAI_API_KEY`
